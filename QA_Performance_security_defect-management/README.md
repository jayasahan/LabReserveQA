# LabReserve QA Evidence Pack

This folder stores the Member 4 evidence for EC4206: performance testing, security testing, defect management, root cause analysis, and final submission evidence.

Use this structure:

- `nonfunctional/jmeter/` - JMeter test plans, raw results, and load summaries.
- `nonfunctional/security/` - manual OWASP check records and evidence.
- `defects/` - defect register, lifecycle evidence, and RCA files.
- `evidence/sprint-1/` - pilot-run evidence.
- `evidence/final/` - final execution evidence from the agreed build.

Keep secrets out of screenshots and exports. Replace tokens, passwords, MongoDB URLs, and personal data with sanitized placeholders.
